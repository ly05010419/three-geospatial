## 0. Scope & ground rules

1. **WebGPU backend only.** No `isWebGPU()` branching, no `RenderTarget3D`/WebGL fallback paths, no changes to how the WebGL (`packages/clouds/src/*.ts` root) code works. If a WebGL user runs the node, it may throw.
2. **No atmosphere/core package changes.** Everything the clouds port needs already exists: `getAtmosphereContext`, `getSplitScalarIlluminance` / `getSplitIlluminance` / `getIndirectLuminanceToPoint` (runtime.ts), `shadowLengthNode` hooks on `SkyNode`/`AerialPerspectiveNode`, `raySpheresIntersections` / `depthToViewZ` / `screenToPositionView` / `interleavedGradientNoise` (core/webgpu). The clouds→scene composite (WebGL `cloudsEffect.frag` / AerialPerspective overlay) is a 2-line node expression done in the story — no `overlayNode` hook needs to be added to `AerialPerspectiveNode` because the Basic scene has no scene geometry (BSM-on-ground has zero visual contribution there). If a hook turns out to be unavoidable, escalate — it is a scope change.
3. **Meters everywhere** inside cloud math (identical to WebGL). Convert to atmosphere "unit" (km) only at Bruneton-call boundaries via `parametersNode.worldToUnit`, adding `altitudeCorrection` exactly where `clouds.frag`/`clouds.vert` do. Never bake `0.001` literals.
4. **Preserve WebGL quirks bit-for-bit** unless listed as "fixed by design": `marchOpticalDepth` 0.5 fudge at 0 iterations, doubled primary jitter, dead `attenuationFactor` in `marchShadowLength`, localWeather alpha=1 overwrite, haze `cameraHeight·modulation < 0` check, `MediaSample.density` dropped (unused), `getSphericalUv`/`textureCatmullRom` not ported (dead). Fixed by design: the `GROUND_BOUNCE` toggle bug (`nextPowder` test) disappears because powder/groundBounce become static options. Intentional deviations discovered during the visual-parity loop (2026-08-17), all documented in code comments: (a) **frozen STBN slice when non-temporal** — the WebGL march rotates the STBN slice by frame index even without a temporal history to converge it, which only makes the noise crawl; the port pins slice 0 on the non-temporal main march, the non-temporal BSM march and the surface-shadow PCF; (b) **`AtmosphereContext.occludeHigherOrderScattering`** — the WebGL Bruneton runtime omits higher-order (multiple) scattering inside a light-shaft shadow segment while the WebGPU one adds it regardless of occlusion; the flag reproduces the WebGL approximation, defaults to `false` (upstream behaviour) and is set to `true` by the parity story; (c) **y-flip in the `shadowMap` debug view** — `getCascadedShadowMaps()` takes the bottom-left-origin uv of the WebGL `vUv` so the 2×2 cascade layout matches for A/B, so `CloudsMarchNode` flips `screenUV.y` before calling it.
5. **Reuse, don't rewrite, CPU code**: `../CascadedShadowMaps` (+ `../helpers/FrustumCorners`, `../helpers/splitFrustum`), `../CloudLayer`, `../CloudLayers`, `../DensityProfile`, `../bayer`, `../constants`; `STBNLoader`, `DEFAULT_STBN_URL`, `createData3DTextureLoaderClass`/`parseUint8Array`, `Geodetic`, `Ellipsoid` from `@takram/three-geospatial`. All are renderer-agnostic (verified: `CascadedShadowMaps` imports only three math + local helpers).
6. Follow atmosphere/webgpu conventions exactly: one class per `XxxNode.ts` + lower-camel factory, `static get type()`, `/*#__PURE__*/` on module-level TSL, `customCacheKey()` via `hash(...)` for static options, `uniform(x).setName(...)` + `.onRenderUpdate` for dynamic values, `FnLayout` for pure layouts / `FnVar` for texture-or-builder-dependent functions, struct via `struct({...}, 'Name')`, `outputTexture`/`outputTexture3D` for produced textures, `RendererUtils.resetRendererState/restoreRendererState` around internal renders, dispose chains.

## 1. Target architecture

### 1.1 Design decisions

- **D1 — Facade with explicit sub-pass ordering.** `CloudsNode` (TempNode `'vec4'`, `updateBeforeType = FRAME`) owns the whole pipeline and is the only node the app touches. Its `updateBefore(frame)` runs, in order: frame++ → CPU shared-uniform update (layers, offsets, CSM) → `shadowNode.update()` → `marchNode.update()` → `resolveNode.update()`. Sub-nodes are `Node` subclasses (for naming/dispose/setup) but are **not** independently FRAME-updated — the facade drives them, mirroring `CloudsEffect.update()` ordering and avoiding node-graph traversal-order surprises. `setup()` returns the resolved color texture sampled at `screenUV`.
- **D2 — BSM as compute into `Storage3DTexture` slices** (replaces the `framebufferTextureLayer` MRT-into-array hack, which has no WebGPU equivalent). Textures: `bsmCurrent` (rgba16f, `mapSize × mapSize × N`), `bsmDepthVelocity` (rgba16f, same), `bsmResolveA/B` (rgba16f, ping-pong). One dispatch covers `[mapSize.x, mapSize.y, N]`; `globalId.z` = cascade index (per-cascade `mipLevels = [0, 0.5, 1, 2]` indexed by z). Resolve is a second compute (variance clip + `temporalAlpha 0.01`). Consumers sample cascade `i` at `w = (i + 0.5) / N` with `texture3D(...).level(0)` — exact slice isolation under linear filtering, bilinear in xy for PCF. This sidesteps color-attachment limits entirely and follows the repo's own LUT-compute precedent.
- **D3 — Clouds march as raster QuadMesh pass** (needs `dFdx/dFdy` for `getMipLevel` and `.toVertexStage()` for the irradiance varyings): internal `RenderTarget(lowW, lowH, { count: 3, depthBuffer: false, type: HalfFloatType })` with `textures[2].format = RedFormat` (mixed-format MRT is legal in WebGPU), `NodeMaterial.mrtNode = mrt({ output, depthVelocity, shadowLength })` (symbol confirmed in three 0.183.2), fullscreen `QuadMesh`.
- **D4 — Clouds resolve as raster QuadMesh pass**, full-res, `count: 2` MRT (color + shadowLength R16F), resolve/history RT ping-pong with pointer swap + clear-history-on-resize, structured exactly like `TemporalAntialiasNode` (`packages/core/src/webgpu/TemporalAntialiasNode.ts` is the blueprint).
- **D5 — Atmosphere via context.** All shaders resolve `getAtmosphereContext(builder)`; the facade captures the instance in `setup()` for CPU use in `updateBefore` (SkyEnvironmentNode/StarsNode precedent). Internal QuadMesh/compute renders see `renderer.contextNode` (SkyEnvironmentNode proves this works). CPU CSM math does **not** depend on context uniform update timing: the facade recomputes camera-ECEF/sun-world itself from `context.matrixWorldToECEF.value` / `context.sunDirectionECEF.value` (verbatim port of `CloudsEffect.updateSharedUniforms`).
- **D6 — Shared uniform bags by reference.** `uniforms.ts` creates plain objects of TSL uniform nodes (parameter bag, layer bag, BSM bag); the facade constructs them once and hands the same objects to shadow + march nodes — the TSL equivalent of WebGL's shared `Uniform` instances. `CloudDensityProfile` struct becomes 4 plain `vec4` uniforms (TSL has no struct uniforms); semantics identical.
- **D7 — Defines → static class fields** hashed in `customCacheKey()`; changing one requires `postProcessing.needsUpdate = true` (documented). Full table in §1.4.
- **D8 — Composition contract.** `CloudsNode` output = full-res premultiplied `vec4` (rgb radiance, alpha = coverage). Story composes: `aerial.rgb.mul(clouds.a.oneMinus()).add(clouds.rgb)` — identical to `cloudsEffect.frag` / AerialPerspectiveEffect overlay math. Light shafts: `cloudsNode.getShadowLengthNode()` (already `× worldToUnit`, i.e. unit-scaled like WebGL's `METER_TO_LENGTH_UNIT` output) assigned to `aerialPerspectiveNode.shadowLengthNode` **and** `aerialPerspectiveNode.skyNode.shadowLengthNode`.
- **D9 — Textures.** Parity target uses the same hosted assets as WebGL defaults (`DEFAULT_LOCAL_WEATHER_URL` PNG, `DEFAULT_SHAPE_URL`/`DEFAULT_SHAPE_DETAIL_URL` .bin → `Data3DTexture`, STBN via `STBNLoader`) with identical sampler state (mipmapped LinearMipmapLinear + Repeat for 2D; Linear + Repeat, no mips for 3D). Texture inputs are typed `Texture | TextureNode`, so the already-ported procedural nodes plug in via `proceduralNode.getTextureNode()` (OutputTextureNode pulls their compute into the graph) — supported, but *not* the parity path (storage textures lack mips; see risk R5).

### 1.3 Frame data flow

```
CloudsNode.updateBefore ─ frame++, updateCloudLayerUniforms, offsets += v·dt, CSM.update (CPU)
  → CloudShadowNode.update:   compute BSM march  → bsmCurrent + bsmDepthVelocity   [mapSize² × N]
                              compute BSM resolve → bsmResolveA (reads B history)   swap A/B
  → CloudsMarchNode.update:   copyCameraSettings (bayer jitter f%16) → QuadMesh MRT
                              color+depthVelocity+shadowLength @ ceil(size/4)      reads: depthNode, BSM, weather/shape/detail/turbulence/STBN, LUTs via context
  → CloudsResolveNode.update: QuadMesh MRT color+shadowLength @ full res           reads: march MRT + history pair; swap
CloudsNode.setup → texture(resolveOutput, screenUV)                                story: aerial.mul(1-a).add(clouds.rgb); shadowLength → sky/aerial hooks
```

### 1.4 Master mapping tables

**WebGL atmosphere-bag uniforms → context** (used by both passes): `bottomRadius` → const from `context.parameters.bottomRadius` (meters, captured at setup); `worldToECEFMatrix` → `context.matrixWorldToECEF`; `ecefToWorldMatrix` → `context.matrixECEFToWorld`; `altitudeCorrection` → `context.altitudeCorrectionECEF`; `sunDirection` → `context.sunDirectionECEF`; `cameraPosition`(→ECEF) → `context.cameraPositionECEF`; `cameraHeight` → `context.cameraHeight`; `METER_TO_LENGTH_UNIT` → `parametersNode.worldToUnit`; `correctAltitude` → `context.correctAltitude` (no clouds-side flag).

**Bruneton calls → runtime.ts**: `GetSunAndSkyScalarIrradiance(p·km,…)` → `getSplitScalarIlluminance(pUnit, sunDirectionECEF)` `.get('direct'/'indirect')`; `GetSunAndSkyIrradiance` → `getSplitIlluminance(pUnit, n, sunDirectionECEF)`; `GetSkyRadianceToPoint(cam, p, sl, …)` → `getIndirectLuminanceToPoint(camUnit, pUnit, sl, sunDirectionECEF)` `.get('luminance'/'transmittance')`. All points: `(pMeters + altitudeCorrectionECEF).mul(worldToUnit)` exactly as `AerialPerspectiveNode` does. Vertex-stage cache (`vGroundIrradiance`, `vCloudsIrradiance`) → same calls under `.toVertexStage()` (constant across the fullscreen quad, so interpolation parity is exact); used by haze always and by the non-`accurateSunSkyLight` path.

**Defines → static options** (all hashed in `customCacheKey`): `SHAPE_DETAIL`→`shapeDetail=true`; `TURBULENCE`→`turbulence=true`; `SHADOW_LENGTH`→`lightShafts=true`; `HAZE`→`haze=true`; `ACCURATE_SUN_SKY_LIGHT`→`accurateSunSkyLight=true`; `ACCURATE_PHASE_FUNCTION`→`accuratePhaseFunction=false`; `MULTI_SCATTERING_OCTAVES`→`multiScatteringOctaves=8` (JS-side loop unroll); `SHADOW_CASCADE_COUNT`/`CASCADE_COUNT`→`cascadeCount=3`; `SHADOW_SAMPLE_COUNT`→`shadowSampleCount=8`; `SCATTER_ANISOTROPY_1/2/MIX`→`scatterAnisotropy1=0.7/2=-0.2/Mix=0.5` (const nodes, not uniforms — preserves the perf intent); `LOCAL_WEATHER_CHANNELS`→`localWeatherChannels` string from `cloudLayers` (JS swizzle); `POWDER`/`GROUND_BOUNCE`→`powder=true`/`groundBounce=true`; `TEMPORAL_UPSCALE`→`temporalUpscale=true`; `TEMPORAL_PASS`/`TEMPORAL_JITTER`→shadow `temporalPass=true`/`temporalJitter=true`; `PERSPECTIVE_CAMERA`→from camera at build; `DEPTH_PACKING`→dropped (0); `USE_LOGARITHMIC_DEPTH_BUFFER`→mirror `builder.renderer.logarithmicDepthBuffer` like `AerialPerspectiveNode`; `DEBUG_*`→`debugShow: 'none'|'uv'|'sampleCount'|'frontDepth'|'shadowMap'|'velocity'|'shadowLength'` (subset needed for verification).

All remaining WebGL uniforms keep their exact names, defaults, and owners (march uniforms on `CloudsMarchNode`, shadow-march uniforms on `CloudShadowNode`, resolve uniforms on `CloudsResolveNode`) — see report tables; defaults are the `high` preset.

## 4. Ten hardest parity risks & neutralization

- **R1 — Bayer/jitter sequence parity** (frame phase, `bayerOffsets` vs shader `bayerIndices` transpose, projection elements [8]/[9] col-major, `jitter·2` NDC scale). *Neutralize*: reuse `../bayer.ts` CPU tables unmodified; port the shader const table digit-for-digit; keep all jitter math on the CPU (verbatim `copyCameraSettings`); M1/M4 probe renders black only when `bayerIndices[x%4][y%4]==frame%16` reconstruction holds.
- **R2 — Y-flip / UV-origin conventions** (WebGPU RT sampling vs WebGL, `screenUV` vs `vUv`, `textureLoad` row order, velocity sign, `screenToPositionView`'s internal `flipY`). *Neutralize*: use `screenUV` + core transformations exclusively; never hand-roll a flip; copy `TemporalAntialiasNode`'s conventions for history/velocity; `debugShow:'uv'` checker and `'velocity'` A/B against WebGL debug views on both axes of camera motion.
- **R3 — Depth conventions** (NDC z ∈ [0,1], perspective/ortho, potential log-depth, `depth ≥ 1` sky test). *Neutralize*: route every depth read through core `depthToViewZ`/`screenToPositionView` exactly as `AerialPerspectiveNode` does (proven against the same passes); scene-clamp verified by placing the M2 debug box in front of clouds.
- **R4 — BSM array→3D-slice representation** (cross-slice bleed, PCF taps crossing cascade bounds, cascade-count changes). *Neutralize*: sample at `w=(i+0.5)/N` (probe b proves isolation); PCF offsets xy-only; `getFadedCascadeIndex` dithered fade ported verbatim; M3 slice-viewer A/B against WebGL `showShadowMap`.
- **R5 — Mip & filtering differences** (weather PNG mipmapped + `textureLod` in WebGL; procedural StorageTextures have no mips; half-float linear filtering; Repeat on 3D). *Neutralize*: parity path uses identical assets with identical sampler state; `getMipLevel`+`mipLevelScale` math verbatim; when a procedural (mip-less) texture is supplied, clamp its sample level to 0 and document the shimmer delta; check `isFloatLinearSupported` once at setup.
- **R6 — Half-float range/NaN** (`frontDepth` sentinels `2e5`/`1e6` exceed f16 max 65504 → inf in the BSM/depthVelocity buffers; inf/NaN poisons variance clipping and history). *Neutralize*: keep formats identical (WebGL has the same overflow and its decode tolerates it via `max(0, …)`); port decode exactly; add an M3 assertion view rendering magenta on `isnan/isinf` of resolved BSM; if WGSL f32→f16 conversion behavior differs visibly, clamp encodes to 65000 on **both** the port and a WebGL test build to confirm no visual change before adopting.
- **R7 — STBN & noise indexing** (normalized-uv `texture()` vs texel fetch, wrap mode, `frame % depth` phase, IGN rotation seed `gl_FragCoord + temporalJitter·resolution`). *Neutralize*: use `textureLoad` with integer `mod`-by-size coords (exact, filter-agnostic); same STBN asset via core `STBNLoader`; IGN from core `generators.ts`; seed expression ported verbatim.
- **R8 — Tone-mapping/color pipeline mismatches** (postprocessing AgX vs three AgX, dithering order, output color space, premultiplied composite order). *Neutralize*: replicate the WebGL order exactly (clouds composite pre-tonemap); exposure 10 on both; verify suspicious luminance diffs with a pre-tonemap `debugShow` output before blaming cloud math; accept the documented sub-1% AgX delta.
- **R9 — GLSL↔WGSL semantics** (`mod` floored vs `%` truncated — critical in `intersectStructuredPlanes` with negative dot products; `pow` of negatives; loop unrolling of `Loop`+`Break`; dynamic uniform-array indexing; ternary vs `If` evaluation). *Neutralize*: M1 probe (d) pins TSL `mod` codegen — if truncated, ship a local `modFloor` and use it at every `mod` site; audit each `pow` base for non-negativity (weather `weatherExponents` operates on saturated values — safe); prefer TSL `select` only for side-effect-free branches.
- **R10 — Temporal lifecycle** (history clear on resize/toggles, swap order vs `outputBuffer` identity, frame-counter start, `deltaTime` source, first-frame garbage feeding α=0.01 BSM history for ~100 frames). *Neutralize*: port `swapBuffers` order exactly (output = just-written target); adopt TAA's `needsClearHistory` on resize/rebuild *and* on `lightShafts/temporalUpscale/cascadeCount` toggles; expose `cloudsNode.resetHistory()` for deterministic captures; capture protocol §3.4 waits 120 frames.

- Visual-parity tuning of `low`/`medium`/`ultra` presets (mapped but only `high` is validated), procedural-texture parity beyond what's already ported, scene-geometry stories (3D tiles), world-origin rebasing story.
- Perf work beyond what the WebGL architecture already implies (¼-res + temporal). No compute-ification of the march pass.
- CHANGELOG/docs beyond an optional short `WEBGPU.md`.
