## 视觉 A/B 对比（WebGPU vs WebGL）

**端口：WebGPU Storybook 4006，WebGL Storybook 4402。**（4004 / 4400 属于另一个 checkout。）

```sh
# 两侧 Storybook（各自一个终端）
pnpm exec nx storybook storybook-webgpu -- --port 4006
pnpm exec nx storybook storybook -- --port 4402

# 对比工具自测（合成图，无需浏览器）
python3 scripts/visual-compare/compare.py --selftest   # 通过时打印 SELFTEST PASSED

# 一轮完整 A/B：顺序采集两张图（共享 GPU，不并行）再出指标
scripts/visual-compare/run-ab.sh round3
```

`run-ab.sh` 的默认对象：

```text
WebGL   http://localhost:4402/iframe.html?id=clouds-minimal-setup--minimal-setup&viewMode=story
WebGPU  http://localhost:4006/iframe.html?id=clouds-clouds--basic&viewMode=story&args=pixelRatio:1;dithering:!false;qualityPreset:high
```

可用 `VC_WEBGL_URL` / `VC_WEBGPU_URL` / `VC_OUT` 覆盖；额外参数透传给 `capture.mjs`。

验证项：

1. 采集参数两侧一致：1600×900、dpr 1、`--settle-frames 240`（时序链收敛：云层升采样 16 帧周期，BSM α=0.01 需约 100 帧）。
2. 先跑无云基线（WebGL `clouds:!false`，WebGPU `coverage:0`），把大气自身的差异从云的差异里剥离。
3. 再跑完整画面，读 `metrics.json`：`rmse_full_pct`、`changed_pct_16`、`largest_blob`。判"肉眼是否看得出"以 `largest_blob`（结构性）为准，RMSE 会被全局偏色主导。
4. 差异定位用两侧同名的 `debugShow`：`shadowMap`（BSM 2×2 级联拼贴）、`shadowLength`、`frontDepth`、`velocity`、`uv`、`sampleCount`。
5. 用 `blink.gif` / `triptych.png` 做最后的肉眼确认。

当前结果（round3）：全图 RMSE 2.16%，差异 >16/255 的像素 0.26%，最大结构连通块 9 px，逐区域的云致暗化与 WebGL 一致（例如地平线以下洋面 R 通道 -41.6 vs -41.6）。逐轮记录见 `docs/visual-compare/log.md`。
