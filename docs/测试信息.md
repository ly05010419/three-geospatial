## WebGPU 端到端运行时测试

页面：

```text
http://localhost:4400/iframe.html?id=clouds-clouds--basic&viewMode=story&args=animateClouds:true;animateDate:true;showShadowReceiver:true;surfaceShadows:true;bsm:true
```

验证项：

1. Storybook body 进入 `sb-show-main`，不再停留在 preparing 状态。
2. WebGPU canvas 已创建。
3. 同时开启云动画、日期动画、BSM、自适应地表云影和接收盒子，连续运行至少 15 秒。
4. 关闭再开启 `surfaceShadows`，确认节点图可重新编译且没有新增 WebGPU shader/console error。
5. 关闭 `animateClouds` 后天气偏移停止；重新开启后按 `cloudSpeed` 继续移动。

当前结果：上述运行时场景通过，无新增 console/GPU 编译错误。

Custom Layers 页面：

```text
http://localhost:4400/iframe.html?id=clouds-clouds--custom-layers&viewMode=story&args=animateDate:true;longitude:45;latitude:20;height:1500;timeOfDay:18
```

验证项：

1. Storybook 注册 `clouds-clouds--custom-layers`，manager 中显示 Location、Local Date、日期动画、Tone Mapping 和 Renderer controls。
2. Basic 专用的云层质量与调试 controls 在 Custom Layers 中隐藏。
3. 修改经纬度与观察高度后 WebGPU canvas 正常创建；日期动画连续运行至少 15 秒。
4. 四个天气通道的自定义云层同时参与主步进与 BSM 云影步进，无新增 WebGPU shader/console error。
5. 带平移的局部参考系满足 World→ECEF→World 往返误差小于 `1e-8`。
6. 默认关闭 `temporalUpscale`、BSM `temporalPass` 与 `temporalJitter`，静止画面不再引入时序像素跳动。

当前结果：Custom Layers 默认参数连续运行 25 秒、位置与日期动画变体连续运行 22 秒，均无新增 WebGPU/console error。

说明：当前自动化 Chrome 的截图 API 不包含 WebGPU 合成层，因此视觉像素基线需要使用能捕获 GPU surface 的测试环境补充；这不影响着色器编译与交互分支回归。
