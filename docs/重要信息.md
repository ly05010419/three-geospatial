# 重要信息

更新时间：2026-08-17

## WebGPU Clouds 阴影数据流

```text
CloudShadowNode（生成 BSM）
  ├─ CloudsMarchNode：云内部自阴影，读取 maxOpticalDepth + tail
  └─ CloudsNode.getSunTransmittanceNode()
       └─ AerialPerspectiveNode：物体表面太阳直射光，仅读取 maxOpticalDepth
```

- `CloudsNode` 是 BSM 生产者与消费者之间的公开门面，表面光照不应直接依赖 `CloudShadowNode` 内部实现。
- `AerialPerspectiveNode.sunTransmittanceNode` 是可选工厂；为空时行为与原 WebGPU 版本完全一致，存在时只乘到太阳直射照度，天空间接照度和月光不受影响。
- 表面阴影需要 Aerial Perspective 接收 normal attachment；Basic 使用 MRT 输出 `diffuseColor` 和 `normalView`。
- 表面阴影的相机 view/projection/near 使用 `CloudsNode` 自有显式 uniform。不要替换成名为 `viewMatrix` 的相机 `ReferenceNode`，否则会与全屏通道绑定冲突并生成非法 WGSL。
- BSM cascade count 和 shadow sample count 是着色器常量；切换 quality preset 后必须标记后处理节点需要重建。
- Basic 默认保持静态和隐藏接收盒子，便于稳定比较；动画与 `showShadowReceiver` 都通过 Storybook controls 显式开启。
- `CloudShadowNode` 的三维计算核必须用 `computeKernel()` 创建；禁止把 `compute(1, ...)` 当成稍后可覆盖的默认尺寸，否则 TSL 会永久加入只允许首个 invocation 执行的 count 守卫。
- 2026-08-17 当前状态：march/current BSM 与 temporal resolve 都已验证有效。Basic 在 `temporalUpscale` + `temporalShadows` 全开下已与 WebGL 参照页对上云影画面，早期"temporal resolve A/B 全零"的记录已作废。Custom Layers 仍关闭 temporal shadow pass，那是展示页的稳定性选择，不是未完成项。

## WebGPU Clouds 自定义云层数据流

```text
CloudLayers（层参数 + RGBA 通道顺序）
  └─ CloudsNode.setCloudLayers()
       ├─ CloudsMarchNode.localWeatherChannels
       ├─ CloudShadowNode.localWeatherChannels
       ├─ layer uniforms
       └─ resetHistory()
```

- 云层数值参数通过共享 uniform 更新；天气通道 swizzle 会进入着色器节点图，必须同步到主步进和云影步进。
- `storybook-webgpu/src/clouds/Clouds-Basic.tsx` 是可配置场景入口：默认保持原 ECEF Basic 行为，`localFrame` 仅供需要位置 controls 的示例启用。
- Custom Layers 在 North-Up-East 局部坐标中保持相机与云层的相对关系，位置 controls 只更新世界到 ECEF 变换，因此无需在每次经纬度变化时重建相机。
- `AtmosphereContext.matrixECEFToWorld` 必须使用 `matrixWorldToECEF.invert()`；North-Up-East 矩阵带有 ECEF 平移，严禁改回只适用于纯旋转的 `transpose()`。
- Custom Layers 通过 `temporalShadows={false}` 使用确定性的当前帧 BSM，并将 Story 的 `temporalUpscale` 默认设为 `false`；这是展示页的稳定性选择，不改变 Basic 默认策略。

### 差异三桶分类

每发现一处差异，先归到下面三桶之一再决定怎么做：

| 桶       | 含义                                  | 处理方式                                                                                                                                                                                            |
| -------- | ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| bug      | WebGPU 侧写错了                       | 修代码 + 补单测（本次：B-20260817-001 ~ 006）                                                                                                                                                       |
| 有意改进 | 两版做法都自洽，WebGPU 选了不同近似   | 加显式开关，默认保持上游行为，由对比 Story 打开（本次：`occludeHigherOrderScattering`）                                                                                                             |
| 平台差异 | 后端能力/实现本身不同，无法也不必消除 | 记录为已知偏差并接受（SMAA、AgX 实现、LensFlare 实现、时序噪声相位、half-float 舍入、大气 LUT 精度）。注意：上游**默认值**不同（如 `groundAlbedo` 0.3 vs 0.1）不属于本桶，应做成 Story 侧的显式 arg |

### 相关约定

- `AtmosphereContext.occludeHigherOrderScattering` 默认 `false`（保持上游：高阶散射不受局部遮挡影响）。Clouds Basic Story 默认设为 `true` 以对齐 WebGL 在光轴阴影段内省略高阶散射的近似。改这个默认值等于改所有上游使用者的画面。
- Clouds Basic Story 的对比相关默认值：`toneMappingMode = AgX`（不是 AgXPunchy）、`toneMappingExposure = 10`、`dithering / lensFlare / raymarchScattering / accurateShadowScattering` 均为 true。
- `shadowMap` 调试视图的 uv 需要翻转 y：`screenUV` 左上角原点，WebGL `vUv` 左下角原点，翻转后两边的 2×2 级联布局才能直接对位。
- `CloudsNode` 不再硬编码 `shadowMaps.maxFar`；默认跟随 `camera.far`（与 WebGL `CascadedShadowMaps` 一致）。参照页 WebGL `Minimal Setup` 与 WebGPU Basic 都不设置 maxFar（同为 4e5）；需要 WebGL Basic 那种 1e5 时通过 `options.shadows.maxFar` 传入。
- **`groundAlbedo` 预计算参数是大气基线偏色的根因**（round4 定位）。它只被多重散射 LUT 预计算消费（`packages/atmosphere/src/webgpu/multiscattering.ts` 的地面反弹项），运行时着色器不读它。
  - WebGL `AtmosphereParameters` 默认 **0.1**（`packages/atmosphere/src/AtmosphereParameters.ts:164`），随包发布的预计算 LUT 贴图就是按 0.1 生成的；WebGPU 上游默认 **0.3**（`packages/atmosphere/src/webgpu/AtmosphereParameters.ts:113`）。地面反弹能量差 3 倍，天空与空间透视整体被抬亮 3~9/255 且偏暖。
  - **WebGPU 包默认值保持 0.3 不变**（改它等于改所有上游使用者的画面）；只有 Clouds Basic Story 把 `groundAlbedo` 做成 number arg（range 0–1，step 0.01）并默认 **0.1**。Custom Layers 用 hiddenControl 隐藏。
  - 运行时改动方式：`atmosphereContext.parameters.groundAlbedo.setScalar(v)` + `atmosphereContext.lutNode.needsUpdate = true` + `cloudsNode.resetHistory()`。`AtmosphereLUTNode.updateBefore()` 用 `version` 判定重算，每次重算都从 `AtmosphereLUTTextures.createContext()` 新建 context 并重编译计算核，所以常量会被重新烘焙。**不需要**重建后处理管线。
  - 修正后：无云基线 RMSE **1.98% → 0.552%**（`mean_abs_diff` 4.505 → 1.070，`changed>8` 8.27% → 0.012%，无结构块）；有云全图 RMSE **2.16% → 0.976%**，最大连通块 88 px，判定 noise-only。
- 剩余的已知并接受偏差：时序噪声相位差（现在是最大的一项）、0.552% 的 LUT 精度/采样残差、LensFlare 实现差异（≤1/255）、WebGL 侧 SMAA、AgX 实现差异、half-float 舍入。
